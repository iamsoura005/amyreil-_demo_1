## 1. Global Navigation & Sitemap

The website is structured into **5 Core Pages** to maintain a clean, high-converting user journey without adding unnecessary steps (reflecting the core value of *Efficiency*):

1. **Home (`/`)** — High-impact overview, value proposition, core services preview, and primary conversion point.
2. **About Us (`/about`)** — Company philosophy, Vision, Mission, Core Values, and our remote-first agency DNA.
3. **Services (`/services`)** — Deep dive into our 5 core service offerings and how we execute them.
4. **Our Approach / Products (`/approach`)** — Showcasing our methodology for building original SaaS products and refusing to build generic clones.
5. **Contact (`/contact`)** — Frictionless project inquiry form and direct communication channels.

### Global Header Component
* **Logo:** Amyreil Technologies (Icon + Wordmark)
* **Nav Links:** `Home` | `About Us` | `Services` | `Our Approach` | `Contact`
* **Primary CTA Button:** `Start a Conversation` (Links to `/contact`)

### Global Footer Component
* **Brand Summary:** 
  * **Headline:** Amyreil Technologies
  * **Subtext:** Building SaaS products and digital solutions that tackle real-world challenges through original thinking, purposeful engineering, and practical design.
* **Status Badge:** `Independent Agency • Remote-First`
* **Quick Links:** `Home`, `About`, `Services`, `Approach`, `Contact`
* **Services Links:** `SaaS Development`, `Web & App Development`, `AI Automation`, `UI/UX Design`, `Data Analytics & Chatbots`
* **Copyright:** `© 2026 Amyreil Technologies. All rights reserved.`

### PAGE 4: OUR APPROACH (`/approach`)

#### Section 4.1: Page Header
* **Eyebrow Text:** `HOW WE THINK & BUILD`
* **H1 Headline:** No generic clones. Only purposeful products.
* **Subheadline:** Most software adds more menus, more clicks, and more complexity. Here is how Amyreil Technologies approaches problem-solving differently.

#### Section 4.2: The 4-Step Amyreil Methodology
* **Layout Hint:** Vertical timeline or 4-step process cards.
* **Step 01: Ask the Right Questions**
  * **Copy:** Before we write code or draw wireframes, we challenge the premise. Why does this problem still exist? What are conventional tools missing?
* **Step 02: Strip Away the Steps**
  * **Copy:** Guided by our core value of *Efficiency*, we map out the user journey and ruthlessly eliminate unnecessary steps, inputs, and cognitive load.
* **Step 03: Purposeful Engineering**
  * **Copy:** We build with clean, modern architectures designed for *Effectiveness*—ensuring the product performs effortlessly under the pressure of daily real-world use.
* **Step 04: Ship Market-Ready Value**
  * **Copy:** We don't release half-baked experiments or copycat templates. Every product we ship has a clear reason to exist and delivers measurable utility from day one.

#### Section 4.3: Comparison Table (The Amyreil Difference)
* **Layout Hint:** 2-Column Comparison Grid (`Conventional Approach` vs. `The Amyreil Way`).
* **Row 1:**
  * *Conventional:* Recreating existing templates and following familiar patterns.
  * *Amyreil:* Questioning assumptions to find fresh ways of solving overlooked problems.
* **Row 2:**
  * *Conventional:* Packing in bloated features that add steps to daily workflows.
  * *Amyreil:* Cutting complexity so everyday work gets noticeably easier.
* **Row 3:**
  * *Conventional:* Optimizing for a flashy launch day demo.
